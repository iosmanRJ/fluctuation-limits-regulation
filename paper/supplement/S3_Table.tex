\sititle{S3 Table.}{Results for every arm of every experiment}

Values are means $\pm$ standard deviations over populations, the unit of
analysis. They are generated by \texttt{paper/supplement/make\_s3.py} from the
per-run files \texttt{paper/data/evosim\_runs.csv}, \texttt{raevol\_runs.csv},
\texttt{grain\_runs.csv}, \texttt{decomp\_runs.csv} and \texttt{confirm\_runs.csv},
which contain one row per run with the same summary measures used in the
pre-registered analyses (the final 20\% of each run for EvoSim and generations
25{,}001--30{,}000 for R-Aevol, except the exploratory decomposition, which uses
generations 30{,}001--32{,}000 of continued runs). R-Aevol values describe the best
individual in each population, as recorded by the platform. Total regulatory
strength $S$ is the number of regulatory links times their mean strength, and is
zero for generations with no links.
